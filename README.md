In this project, four recipes you can try. It is built using HTML that has be learned from The Odin Project. In this course we learn about HTML, CSS, and JavaScript. The last two comes later on. We also learned about GitHub and how to commit our work to the platform.

As for the recipes, these are chosen by the author of what he enjoys to eat. They are weight-loss recipes to get you fit and don't contain mushrooms, just in case you are allergic to them like the author.

We hope that you enjoy them.
